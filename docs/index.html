它需要什么都会，但只做一件事

打开就写，写完就走。

Notchpad 把记事压缩到最短路径：唤醒、输入、收起。其余能力都围绕这件事展开，不喧宾夺主。

A
刘海交互，两种唤醒
平时收成屏幕顶部的一颗小药丸，悬浮或点击即可展开，收起时带弹性动画。收起状态下药丸还能轮播时钟、一言、天气或自定义文字。
悬浮 / 点击Jelly 弹跳多显示器全局快捷键系统托盘
B
富文本编辑，斜杠菜单更快
基于 TipTap 的编辑器支持标题、列表、待办、引用、代码、链接与图片粘贴压缩。输入「/」唤出块菜单，用中英文或拼音关键词筛选，方向键选择、回车插入。
斜杠菜单字体字号颜色高亮图片压缩字数统计
C
多页面与跨页整理
顶部标签切换页面，拖拽排序、置顶、双击改名。Ctrl+F 跨页搜索标题与正文，删除的页面在回收站保留 24 小时，随时可恢复。
标签页拖拽排序跨页搜索回收站
D
外观由你决定
四套主题风格包、明暗与跟随系统、13 色强调色。可以铺一张壁纸，单独调遮罩、模糊、内容区透明度与毛玻璃，并选择全局默认字体——从枚举出的系统字体里挑，或跟随系统。
四套主题面板壁纸全局字体13 色强调色
E
数据在本地，迁移也简单
SQLite 即时落盘，图片以附件文件存放。可自定义存储目录、清理未引用附件，支持 JSON 导入导出与 Markdown 导出，更新包经签名校验。
